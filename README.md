# haxedecomp

a .swf decompiler for Haxe — an alternative to JPEXS, which decompiles haxe written files badly because it's made for .as only,

## How to use

decompile to a file:

```cmd
haxedecomp.exe test.swf --decompile > out.hx
```

view the output instantly:

```cmd
haxedecomp.exe test.swf --decompile
```
